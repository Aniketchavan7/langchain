# Files

- [Agent Execution: Loop Structure and Lifecycle](agent-execution.md) - How agents run: the basic loop, state management, middleware integration, and human-in-the-loop patterns. Covers the agentic loop, tool calling, structured output, middleware composition, and approval workflows.
- [Composability: Chaining & Piping Runnables & Hierarchical Agents](composability.md) - Learn how to build complex applications by composing runnables through pipe operators, parallel execution, branching, and fallbacks. Includes composition patterns, type safety, configuration threading, hierarchical agent delegation, middleware stacking, and debugging techniques.
- [Middleware: Pre/Post Processing and Interrupts](middleware.md) - Middleware architecture for agents: request/response interceptors and lifecycle hooks that transform execution, control state, validate inputs, and pause for human review via LangGraph interrupts. Covers composition, state management, interrupt patterns, and human-in-the-loop approval.
- [Model Initialization: init_chat_model Provider Routing](model-initialization.md) - How init_chat_model routes model identifiers to provider-specific implementations. Covers model identifier syntax, provider discovery, lazy module loading, _ConfigurableModel, model profiles, and capability detection.
- [Streaming: Token-by-Token Output and Events](streaming.md) - Streaming in chat models delivers responses incrementally through chunks and structured events. The system supports V1 callback-based streaming, V2 event-based iteration, and V3 protocol events with typed projections for text, reasoning, tool calls, and usage metadata.
- [Structured Output: Type-Safe Results from Language Models](structured-output.md) - Patterns for obtaining structured, validated output from language models using Pydantic schemas, JSON schemas, and output parsers. Bind schemas to chat models with with_structured_output() or parse raw model responses using BaseOutputParser implementations. For agents, use ToolStrategy, ProviderStrategy, or AutoStrategy to enforce structured output.
